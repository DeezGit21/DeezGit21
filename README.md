## 🔮 Featured: [JARVIS Deck](https://github.com/DeezGit21/jarvis-deck)

An open-source, self-hosted personal AI assistant with a voice HUD — hold a
button, talk, and it answers **out loud about one second later**. Plasma
neural orb, memory galaxy, realtime sentence-streamed TTS, real agent
actions (it runs my business backend, reads my inbox, executes scheduled
jobs). No cloud assistant, no fake demo data.

▶ **[Watch the 30-second demo](https://www.youtube.com/watch?v=gynzOFzN8D4)**
